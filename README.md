## 🚀 Projetos em destaque

### 🏭 Sistema Industrial de Detecção de Falhas

Aplicação de Machine Learning que estima a probabilidade de falha em máquinas industriais a partir de dados de sensores. O projeto inclui análise exploratória, comparação de modelos, validação cruzada, ajuste do limiar de decisão e análise dos erros.

**Status:** ✅ Aplicação publicada no Streamlit, resultados documentados e conteinerização com Docker disponível.

**Resultados no conjunto de teste:** o modelo Random Forest identificou **49 dos 68 casos de falha**, com **recall e F1-score de 72,06%** e **acurácia de 98,10%**.

**Tecnologias:** Python · Pandas · NumPy · Scikit-learn · Random Forest · Joblib · Streamlit · Docker

[🔗 Ver projeto](https://github.com/joaovitorsoska/Sistema-industrial-deteccao-anomalias) · [🌐 Acessar aplicação](https://sistema-industrial-deteccao-anomalias-hvx49utk9wyhcyj9decnee.streamlit.app)
